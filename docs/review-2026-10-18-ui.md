# UI 점검 (2026-10-18)

기준: Linear 앱 스크린샷(차분한 다크, 낮은 대비 라벨, 얇은 선, 일정한 한 줄 높이, 강조색 한두 곳). 데스크톱 1280x800과 휴대폰 390x844에서 실제로 띄워 비교했습니다. 스크린샷은 `/tmp/shots-ui/before-*`, `after-*`에 있습니다.

## 요약

1. 토큰과 기본 모양(어두운 배경, 얇은 선, 작은 글자)은 이미 Linear 쪽이라 크게 손댈 곳은 적었습니다. 문제는 한 화면에 컨트롤이 너무 많이 동시에 펼쳐져 있다는 점이었습니다.
2. 가장 복잡한 곳은 KP 굴림 탭(판정 요청 폼 + 비밀 굴림 + 매크로 + 입력 + 도움말 줄 + 저장 버튼이 한꺼번에 쌓임)과 KP 하단 도구 줄 4개였습니다.
3. 판정 요청 폼을 한 줄(`판정 요청 ▸`)로 접고, 하단 도구 줄을 4줄에서 2~3줄로 줄였고, 장면 막대를 2줄에서 1줄로 줄였습니다.
4. 로비 카드는 크고 채도 높은 버튼이 줄마다 반복돼서 한 줄짜리 목록으로 바꿨습니다. 시트 탭은 섹션 제목과 일정한 줄 높이를 넣었습니다.
5. 기능, data-testid, aria-label, 버튼 이름은 그대로입니다. 접은 컨트롤을 쓰는 e2e 두 군데(판정 요청, 안개 더보기)만 펼치는 단계를 넣었고, 전체 e2e와 typecheck, arch, test가 통과했습니다.

## 발견한 문제 (심각도 순)

높음
- 굴림 탭(KP)이 입력 영역만 세로 약 300px를 차지하고, 휴대폰에서는 판정 요청 폼이 화면 대부분을 덮어 굴림 기록이 거의 안 보임. `widgets/roll-panel/ui/RollPanel.tsx`, `RollAsk.tsx`, `features/roll-macros/ui/MacroBar.tsx`
- KP 하단 도구가 안개/단축키/놓기/선택 4줄로 쌓여 지도가 줄어듦. 줄마다 라벨 위치가 중앙 정렬이라 제각각. 안개를 켜면 컨트롤이 10개 가까이 늘어남. `globals.css`(.dock), `features/manage-fog/ui/FogToolbar.tsx`
- 시트 탭 안쪽이 따로 스크롤되어 하단(토큰으로 놓기 등)과 겹쳐 잘림. 섹션 제목이 없어 상태, SAN, 판정, 기능이 한 덩어리. `widgets/sheet-panel/ui/SheetPanel.tsx`, `views/room/ui/RoomView.tsx`
- 알림창(토스트)이 하단 중앙에 떠서 하단 도구 버튼을 가림. 안내 배너(top 108px)는 장면 막대(2줄)에 일부 가려짐. `globals.css`

중간
- 룸 카드마다 채도 높은 `룸 열기` 큰 버튼 + KP/상태 배지 두 개 + 삭제가 반복되어 위계가 없음. `entities/room/ui/RoomCard.tsx`
- 컨트롤 높이가 24/26/28/30/32/34로 섞여 있어 입력과 버튼의 줄이 안 맞음(굴림 입력 30 + 굴리기 26). 반경도 4/5/6/8/10/12가 섞임. `globals.css`
- 패널마다 `primary` 버튼이 전폭으로 깔림(새 핸드아웃, 전투 시작, 파일 고르기, SAN 체크 등). 강조색이 한 화면에 여러 곳.
- 헤더 배지 3개가 모두 테두리 있고, 세션 종료가 빨간 테두리로 계속 눈에 띔. `widgets/room-header`, `features/session-control`
- 장면 막대 2줄 중 아래 줄은 거의 비어 있고 `보고 있는 장면: 장면 1 (진행 중)` 문구가 점 표시와 중복. `features/manage-scenes/ui/SceneBar.tsx`

낮음
- 휴대폰에서 줌 버튼(+/-)이 하단 도구 줄과 겹침.
- 캐릭터 편집 폼의 기능 47개가 한 줄씩 길게 이어짐(세로 약 1500px). `features/edit-character/ui/CharacterForm.tsx` (이번엔 손대지 않음)
- 룸 입장 때마다 `다시 연결됐어요` 알림이 뜸(아래 남은 이슈).

## 한 일

- `globals.css`: `--row: 28px`, `--row-lg: 32px`, `--radius-md: 8px` 토큰 추가. 버튼과 입력 높이를 28로 통일하고 패널 안 버튼 26 예외를 없앰(칩용 `sm`은 24). 배지는 테두리를 없애고 옅은 배경으로, KP와 일시정지만 색 유지. 연결 상태는 점 + 글자로 조용하게. 알림창은 위쪽 중앙으로 옮기고 클릭이 통과하게 함. 배너와 가이드 위치를 장면 막대 아래로.
- 굴림 탭: `판정 요청 ▸`를 한 줄로 접고 펼치면 폼(보낸 뒤 자동으로 접힘). 입력 + 굴리기를 한 줄로, 비밀 굴림 체크 + `규칙 도움말`(접기) + 굴림 기록 저장을 한 줄로. 매크로 줄은 테두리 없이 입력 위에 붙임. 매크로가 없을 땐 안내 문구를 없애고 `매크로 편집` 버튼만 남김.
- 하단 도구: 안개와 놓기를 한 줄에 나란히(2열), 단축키 줄, 선택 줄(선택했을 때만). 라벨은 고정 폭 열로 정렬하고 왼쪽 정렬. 빈 단축키 칸은 좁고 점선. 안개는 `안개 켜기/끄기`, `영역 밝히기`, 반지름, 영역/탐험 수만 보이고 나머지(시야 입력, PL 전원 시야, 탐험 기록 지우기, 되돌리기, 모두 지우기)는 `더보기 ▾`에.
- 장면 막대를 한 줄로(탭 | 새 장면 | 장면 설정). 지금 장면을 보고 있을 땐 문구 없음, 준비 중일 때만 `준비 중 — PL에게 안 보여요`. `바로 전환`도 일반 버튼으로.
- 헤더: 세션 종료를 평소엔 조용한 글자, 마우스를 올리면 빨강. 중복 구분선 정리.
- 로비: 카드 그리드를 한 줄 목록(제목/메타 | 배지 | 열기)으로. 삭제는 마우스를 올릴 때만 보임(터치 기기는 항상). 휴대폰에서는 2줄 행.
- 시트 탭: `SAN`, `판정`, `무기`, `기능 N` 섹션 제목, 상태 줄 일정하게, 기능 줄은 28px에 `굴리기`가 평소엔 흐리고 올리면 선명. 시트 전체가 한 스크롤로 움직임(RoomView에서 클래스 이름만 바꿈).
- 핸드아웃, 전투, 음향, 흐름 패널: 전폭 primary를 작은 버튼 + 패널 머리 줄로. 음향 `파일 고르기`는 일반 버튼.
- e2e(`apps/web/e2e/room.e2e.mjs`): `openAsk`, `openFogMore` 도우미를 넣어 접힌 컨트롤을 펼친 뒤 쓰게 함.

## 남은 제안

- 입장할 때마다 `다시 연결됐어요` 토스트가 뜸. `reconnected` 카운터가 첫 연결에도 올라가는 것으로 보임(`features/room-realtime`, 이번 범위 밖).
- 캐릭터 편집 폼: 기능 목록을 2열 또는 접기(`기능 47개 ▾`)로, 마법사 단계는 지금도 괜찮음.
- 헤더의 `초대`도 테두리 없는 ghost로 낮추면 `세션 시작`이 유일한 강조가 됨. 지금은 `초대`만 테두리가 있어 눈에 띔.
- 휴대폰 헤더에서 세션 상태 배지가 `…`로 잘림. 상태를 점 하나 + 짧은 글자로 줄이는 것을 제안.
- 단축키 칸 9개를 숫자만 보이는 작은 칩으로 접고 채워진 칸만 이름을 보이는 방안.
- 핸드아웃/흐름 카드 안의 `편집/삭제` 줄도 올릴 때만 보이게 하면 목록이 더 조용해짐.
- Next 개발 모드의 `N` 표시가 좌하단 도구와 겹쳐 보이니, 스크린샷에는 숨겨 찍음(운영 빌드엔 없음).
